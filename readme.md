## 📘 Sobre o Projeto

O **Sistema de Reuso de Água** é uma aplicação desenvolvida em **Python** com **PyQt6** que realiza o **monitoramento do nível e volume de água** em um reservatório.

O projeto simula a leitura de sensores ultrassônicos que medem a **distância até o nível da água**, convertendo esses dados em **volume estimado (litros)** e exibindo em uma **interface moderna**, com **gráficos, tabela de leituras e barra de progresso**.

---

## 🧠 Funcionalidades Principais

✅ Leitura das últimas medições de nível e volume da água  
✅ Atualização dos dados em tempo real com um clique  
✅ Exibição em tabela interativa (ID, distância, volume e data)  
✅ Gráfico com histórico de volume  
✅ Barra de progresso mostrando o nível atual do reservatório  
✅ Conexão segura com banco de dados PostgreSQL  
✅ Layout escuro (dark mode) com design moderno
